# 0.3.0 随手翻译

本版增加划词、悬停和输入框翻译。参考沉浸式翻译先前核查的共享调度/缓存，以及FluentRead的选区、悬停复核和输入快照保护，独立编写实现。没有复制竞品代码；源码永久链接与许可证标识见`fluentread-interaction-reference.md`，竞品静态证据不等于本项目运行证据。

## 使用

在设置或弹窗中分别开启三个入口。初始关闭，首次勾选时申请普通网页权限；现有可访问网页立即加载入口，新页面自动加载。与整页自动翻译独立，保存开关不调用API。

| 入口   | 行为                                                                                                                                                                          |
| ------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 划词   | 选择正文，点击“翻译选中内容”才发送；浮层可看原文、复制、关闭。                                                                                                                |
| 悬停   | 按住Alt并在段落停留450ms，延迟后重新核对目标。普通悬停、其它组合键、编辑中、IME或活动选区不触发。松开Alt取消未开始的计时；鼠标按Alt进入排除区、关闭、滚动或失焦会取消旧工作。 |
| 输入框 | 点击按钮或Alt+T；有输入选区时只译选区，否则译整个编辑区。先预览，确认才替换，可复制和受保护撤销。输入目标语言独立设置，初始English。                                          |

阅读沿用现有目标语言，输入翻译源语言自动识别。每次最多6000 Unicode字符，超限明确提示，不静默截断。Esc关闭。重新翻译、继续下一轮都是用户显式动作，可能再次计费。

## 输入安全与兼容

排除密码、支付/验证码/凭据标记字段（含常见英文标记）、非text/search输入、只读/disabled/ARIA-readonly、代码编辑器、禁止翻译区和不可见内容。普通文字仍可能私人；这不是通用敏感信息识别器。支持标准input/textarea及简单contenteditable；专用富文本编辑器、跨域iframe和封闭Shadow DOM不作通用兼容保证。

替换前检查原元素连接、资格、原文/格式快照、当前配置与文档身份；不按旧ID寻找新节点写入。尊重beforeinput取消和maxlength；原生value setter通知input，简单富文本用原生文本编辑，译文不会作为HTML执行。派发事件后核对实际内容，下一渲染帧再核对；宿主恢复或改写内容时明确报错，不报告成功。撤销必须满足内容仍等于刚应用结果，不覆盖继续编辑。

扩展不点击发送或触发回车。替换会通知原网页，原站自身的自动保存/搜索等输入行为仍可能运行。富文本选定区域会变成纯文本，原格式恢复只在已测试简单编辑区内保证。

## 调用链

```text
勾选/授权 → InteractionSettings保存/动态注册bootstrap
可信页面动作 → 选区/悬停重核/输入快照 → INTERACTION_TRANSLATE
 → InteractionActions验证sender、顶层documentId、实际URL、前台tab
 → 设置快照 → 文档共享Budget → Jobs.prepare查缓存/分片
 → 全局2请求闸门 → 保存已派发计数 → 原有文本服务
 → ID/格式校验 → 请求/配置/来源复核 → 纯文本浮层
输入确认 → INTERACTION_VALIDATE再次核对配置/页面 → DOM快照复核 → 写入/验收
```

偏好/权限、后台请求、DOM快照、浮层和事件控制器分开，三个入口复用既有Jobs、缓存与文本服务；不会重新启动整页翻译。每个document共用每轮300片/60000字符；session ledger只保存计数与文档标识，派发前保存，后台重启不能清零。缓存命中不消费。额度记录失败阻断请求；取消不退还已消费计数，也不能保证远端不计费。额度不是金额账单。

只将当前文字、条目ID、语言和模型参数交给配置服务；不额外发送其它表单字段、完整表单、Cookie或页面URL。文字本身包含私人信息或URL仍可能发送。密钥只在后台使用。

配置/权限/鉴权/网络/格式/超额/陈旧输入错误可见，不自动换服务、重试或注入假译文。缓存是可选加速；剪贴板不可用提示手动复制。初始化失败显示可重连浮层，模块无法加载显示页面通知；旧初始化失败不能覆盖新成功状态。

## 验证边界

具体数字与机器证据见`verification.md`。使用隔离Playwright、真实Chrome DOM/事件和本机模拟服务；IME以组合事件模拟。没有新增真实收费请求、安装日常Chrome或冒称Computer Use验收。真实模型质量/延迟、各种网站编辑器和系统快捷键冲突尚需进一步验证。
