# 网页英语学习 · 0.4.0

从插件弹窗或设置页打开“英语学习 · 设置与学习库”，根据示例选择阅读水平（A1–C2），选择“常用实用”或“文章难点”，开启学习模式并保存。网页访问权限只需首次授予；可随时关闭。划词、Alt 悬停收录需另行开启对应快捷翻译入口。

## 阅读中的完整流程

1. 主动翻译一个词/表达，成功结果自动进入学习库；超过12词或含句末标点的查询初步归为阅读记录，可在学习库手动加入复习。输入框草稿不自动收录。短表达的启发式分类可能误判人名等，可“暂不复习”或删除。
2. 开启学习模式后翻译网页，独立异步推荐至多8个当前原文中确实存在的表达。推荐不会自动加入学习库；点击“加入学习”才安排复习。已有记录再次查询保留复习状态。
3. 网页右下角“学英语”显示重遇提示。打开“本页重遇”，先回忆，再点“揭晓”，选择“记得”“忘了”或“跳过”。也可在学习库集中复习。重遇主要按当前正文文字匹配，尚不做词形/语义匹配或在原文中改写文字。
4. 在正文中选中表达，点击“解释选中表达”，模型结合邻近段落解释俚语、俗语、语域和语境含义。
5. 点“文章练习”，同时生成理解题和词汇表达选择题；作答后显示参考答案、解释和原文证据。答案由AI生成，不是权威测评；证据存在性检查不能证明推理必然正确。

## 数据、费用与边界

- 学习数据单独存于 `chrome.storage.local.englishLearningV1`，不随30天译文缓存失效。存储原文、译文、邻近上下文、去查询参数和fragment的网页路径、复习计数与时间。
- 开启后翻译文章的推荐会额外发出请求；解释和练习只在点击后请求。发送的内容为正文/所选表达及邻近段落、水平和偏好，不发送学习库、Cookie、网址或密钥以外的浏览器凭据。
- 自动推荐和练习当前分析正文前18000字符，面板明确说明范围；不读取输入、可编辑区域、导航、隐藏文本或插件译文层。长文后半部分不会被悄悄当成已分析。
- 使用当前已配置的 OpenAI、DeepSeek 或 Claude 文字服务。Google Cloud Translation 不支持教学生成，明确提示用户配置文字模型；不自动切换服务。沿用请求超时、响应上限和全局最多2个在途请求，学习排队优先级低于翻译。
- 页面切换、关闭学习、变更设置取消或拒绝迟到结果；超时不能保证服务端不计费。不自动重试、伪造题目或调用ASR。
- 学习库支持JSON导出与合并导入；旧条目保留原进度，不导入连接密钥或自动开启学习。当前安全容量3000项/约3MB，超过时明确报错，请先导出整理。清空前确认，仅删除学习数据。

## 水平与复习

用户根据示例自选水平；可选三题短测只给入门参考，不自动改设置，也不声称能测定完整英语能力。复习累计至少5次后显示难度调整建议，练习结束给当前题组反馈。

复习采用简单可解释规则：连续记得的间隔为1、3、7、14、30天，忘了回到1天；跳过不改计划。它不是训练过的个性化记忆模型，单次记得不会标成“永久掌握”。

## 本次范围

普通网页学习流程。本机数据，无账号或云同步。文件与视频字幕学习接入列为后续阶段，已有文件翻译和字幕功能继续保留。

## 回退审计增量

学习库写入失败时翻译结果仍展示，并明确提示“学习记录未保存”；学习分析失败不会用通用模板填充。格式不合法、原文中找不到推荐或证据、缺少两类练习题时整个结果拒绝。存储操作串行化，导入先校验再合并。请求清理中的捕获只用于释放资源，不替换业务结果。

验证结果见 `verification.md` 和 `docs/evidence/learning-0.4.0.json`。真实服务质量、费用及长期记忆提升尚未验证。
